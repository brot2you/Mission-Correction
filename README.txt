MISSION CORRECTION V2 — by brot2you
Ouvrir index.html (Chrome, Firefox, Safari). Déploiement : envoyer index.html, style.css et app.js à la racine d'un dépôt GitHub Pages.

FONCTIONS : 48 défis corrigés, 24 fiches de règles, 7 missions, suivi XP, badges, carnet de correction libre, codes personnalisés, création de parcours à partager, import/export JSON, export TXT des corrections. 6e à 3e. Sans serveur, hors ligne sauf police Google facultative.

IMPORTANT : les réponses aux exercices sont corrigées automatiquement ; les rédactions libres du carnet ne sont PAS évaluées automatiquement. Les codes de parcours ne transportent que les catégories, pas les questions ni les copies. Les données restent dans localStorage sur l'appareil ; utiliser Exporter régulièrement. Le mode professeur n'est pas protégé par authentification. Ne pas stocker de données personnelles sensibles.

Les illustrations SVG et l'interface peuvent être remplacées ultérieurement par des images HD.
